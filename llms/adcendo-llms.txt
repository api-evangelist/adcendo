# Adcendo

> Adcendo ApS is a clinical-stage biopharmaceutical company headquartered in Copenhagen, Denmark, with US operations in Boston, Massachusetts, developing antibody-drug conjugates (ADCs) for cancers with high unmet medical need. Founded in 2017, its pipeline includes ADCE-T02 (Tissue Factor, Phase 1b Tiffany-01), ADCE-D01 (uPARAP, FDA Fast Track for soft tissue sarcoma), and the pre-clinical ADCE-B05.

Adcendo publishes **no public API, no developer portal, and no machine-readable API
contract**. This file is generated by API Evangelist from the public company profile at
`apis.yml`; it is not published by Adcendo. It exists so an agent looking for an Adcendo
